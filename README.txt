폴더 구성
  index.html      → 기존 주소가 깨지지 않도록 maeum/ 으로 보내 주는 파일
  maeum/          → 구름마음 자가검진 (기존 index.html)
  shim/           → 숨쉼 (호흡 가이드 + 마음 건강 OX 퀴즈)
  shared/         → 숨쉼이 쓰는 공통 파일 (config.js 에 통계 코드와 전화번호)

올리는 법: 이 폴더 안의 파일을 통째로 GitHub 저장소 최상위에 올리면 됩니다.
  주소: .../ (구름마음으로 이동) · .../maeum/ · .../shim/
글 수정: shim/content.js
