폴더 구성
  index.html      -> 처음 선택 화면 (구름마음 / 숨쉼 중 고르기)
  maeum/          -> 구름마음 자가검진
  shim/           -> 숨쉼 (호흡 가이드 + 마음 건강 OX 퀴즈)
  shared/         -> 공통 파일 (config.js 에 통계 코드와 전화번호, illus.js 일러스트)

올리는 법: 이 폴더 안의 파일과 폴더를 통째로 GitHub 저장소 최상위에 올립니다.
  주소: .../ (선택 화면) · .../maeum/ · .../shim/
글 수정: shim/content.js

숨쉼에서 고칠 수 있는 곳 (shim/content.js)
  CARDS   마음 카드 문구 (카드는 맨 뒤에 추가)
  WALKS   횡성 산책길 (지금은 비어 있음, 주석의 형식 예시대로 한 곳씩 추가)
